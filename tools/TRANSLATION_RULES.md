# 번역 규칙 (Mingoo 확정, 2026-10-03) — 모든 판에 반드시 적용

[역할] 태국 현지 뉴스를 한국어로 번역·요약한다. 독자는 태국 파타야 등에 사는 한국인. X 트렌드는 수집·번역·표시하지 않는다.

[공통 원칙]
- 직역 금지. 한국 사람이 읽기에 자연스러운 한국어.
- 원문의 사실·숫자·감정 강도 유지. 원문에 없는 정보나 평가 추가 금지.
- 번역문 앞뒤에 "번역했습니다" 같은 군더더기 금지.
- 사건의 핵심과 주요 정보를 먼저 전달.
- 원문의 구어체, 감정, 농담, 비꼼, 의문·감탄을 문맥에 맞게 살린다.

[제목]
- 클릭하고 싶게 임팩트 있게. 의역·어순 변경·강조 허용.
- 핵심 사실·의미에서 벗어나지 않기. 지어내기·과장·왜곡 금지.
- 짧고 강한 뉴스 제목체(명사형 종결 또는 "~다").
- 예외: 사고·사망·성범죄·피해자가 있는 기사는 임팩트는 살리되 선정적으로 쓰지 않는다.
- 한국어 독자는 제목만 보고 한국 주체로 오해할 수 있으므로, 국가가 드러나지 않는 첫 주어·첫 언급에는 `태국 대표팀`(축구 대표팀 포함), `태국 정부`, `태국 총리`·`태국 재무장관`·`태국 경찰청`·`태국 기상청`·`태국 국회`·`태국 중앙은행`, `태국 내`, `태국 국민`처럼 `태국`을 붙인다. 같은 구절에서 방콕시장처럼 태국임이 분명하거나 한국 주체이면 각각 `한국`을 쓴다. 이 원칙은 헤드라인·요약·for_me·브리핑·카카오톡 공유 문구·토론 질문·운영자 댓글에 적용한다.

[본문]
- 간결하고 정확한 뉴스체. 의역 최소화.
- X 게시글·사용자 반응은 짧고 자연스러운 SNS 구어체로 현지 분위기를 살린다. 단, X 게시글 원문을 직접 수집하지 않으므로 "현지 반응"은 뉴스 기사에 인용된 반응만 옮긴다.
- 기사 원문에 포함된 이모지는 문맥에 맞게 유지한다. X 트렌드 해시태그는 번역·편집·출력하지 않는다.
- 태국어 특유의 완곡 표현·풍자는 의미가 자연스럽게 전달되게.
- 심한 욕설·비하 표현은 감정은 살리되 순화하거나 일부를 가린다(예: "X발"). 공유되는 사이트이므로.

[고유명사·숫자]
- 인명·지명은 한국 통용 표기 우선(Pattaya→파타야, Bangkok→방콕).
- 지역 주제·지명 표기(2026-10-03 주제 개편 — 동부(촌부리·라용)·방콕·북부·남부): 주제 이름은 화면 그대로 `동부(촌부리·라용)`·`방콕`·`북부`·`남부`. 지명은 한 판·여러 판에서 같은 표기로 — 촌부리(Chonburi)·파타야·좀티엔·방라뭉·나끌루아·싸따힙·시라차·램차방·방센·라용(Rayong)·맙따풋(Map Ta Phut)·꼬사멧 / 치앙마이·치앙라이·람빵·람푼·매홍손·빠이·난·프래·파야오·핏사눌록·수코타이·매솟 / 푸껫(Phuket)·빠똥·끄라비·팡아·카오락·수랏타니·꼬사무이·꼬팡안·꼬따오·송클라·핫야이·나콘시탐마랏·뜨랑·사뚠·춤폰·라농·빳따니·얄라·나라티왓. 첫 등장 때 필요하면 괄호에 로마자.
- 통용 표기가 없으면 한글 음역 + 첫 등장 시 괄호에 영어(로마자) 표기 병기. 태국 글자는 쓰지 않는다. 예: 아누틴(Anutin).
- 같은 직함·기관명은 항상 같은 번역어.
- 바트 기호 '฿' 는 쓰지 않는다(2026-10-04 Max 승인). 제목·요약·본문·브리핑·키워드·매체 이름·카톡 공유 문구·공유 카드 등 모든 글에서 금액 단위는 '바트'(예: 350바트(약 14,068원)). '฿' 는 사이트 헤더 시세 숫자 칸(환율·USDT·금·휘발유 값 옆 작은 단위)에만 쓴다. `newslib.validate`(판 저장)·`share_kit.py`·`tools/dev/regress.py` 가 막는다.
- 금액은 바트(THB) 유지하고, 모든 금액(작은 금액 포함)에 원화 환산을 괄호로 덧붙인다. 바트와 원화 모두 소수점은 반올림해 정수로만 쓴다(예: 45.50바트 → 46바트(약 1,900원)). 한 판 안에서는 그날 환율 하나로 통일한다(판 데이터/README에 사용 환율 기록). 2026-10-02 저녁판부터 `newslib.krw_check`(판 저장 때 validate)가 화면 글(제목·요약·배경·후속·지역·그래서 나는?·추천 댓글·이슈 이름·오늘의 질문·브리핑)의 바트 금액마다 원화가 바로 뒤에 있는지 보고, 없으면 판 저장을 실패시키며 넣을 글을 판 환율로 계산해 보여 준다. 섞인 단위(13억678만 바트)·범위(300~500바트)도 한 금액으로 본다. 괄호 안 금액은 '(약 14억6,271만 바트, 약 587억8,631만 원)' 처럼. 2026-10-05 아침판에서 요약의 '(약 13억678만 바트)' 가 원화 없이 라이브에 나감 → 그때까지는 for_me·추천 댓글만 검사했음.
- 불기(B.E.) 연도는 서기로 변환(2569→2026).

[모호할 때]
- 번역 문장의 의미가 불확실하면 가장 가능성 높은 번역을 쓰고 끝에 "(원문 의미 불확실)" 표시.

- 옛 판 데이터에 남은 `trends` 필드는 레거시 기록으로만 보존하며, 새 판에는 만들지 않는다. 화면·공유 카드·번역 결과에는 절대 출력하지 않는다.
- 태국 면적 단위는 괄호로 ㎡와 평을 병기하고 정수로 반올림한다. 1라이(rai)=1,600㎡≈484평, 1응안(ngan)=400㎡≈121평, 1따랑와(tarang wa)=4㎡≈1.21평. 예: 35라이(약 56,000㎡, 약 16,940평).

[💬 오늘의 질문·운영자 댓글 — 독자 상황 맞추기, A/B/C 3단계 (Mingoo 확정, 2026-10-18 저녁판)]
- 독자는 태국에 사는 한국인 교민이나 여행자다. 질문·운영자 첫 댓글·운영자 답글(독자 댓글에 다는 답, `drafts/replies`)은 모두 이 사람들의 실제 상황에 맞아야 한다.
- **질문을 쓰기 전에 기사마다 먼저 A/B/C 를 정하고**, 초안 항목에 `reader_fit: "A"|"B"|"C"` 로 적는다.
  - **A. 누구나 이야기할 수 있는 화제**: 연예인, 음식·맛집, 날씨, 사건·사고·범죄, 여행, 스포츠, 물가 등. 같은 동네 사람으로서 평소처럼 묻는다.
  - **B. 외국인·한국인에게도 해당되는 정책·행정**: 비자, 이민국, TM30, 운전면허, 외국인 세금, 관광객 규정 등. 실제로 겪는 일을 1인칭 실용 질문으로 묻는다(예: "90일 신고, 온라인으로 해 보셨나요?").
  - **C. 태국 국민만 해당되는 행정·혜택**: 지원금, 주민등록·신분증, 선거·투표, 태국 사회보장, 태국 학교 규정 등. 독자나 운영자가 직접 해야 하는 일처럼 쓰지 않는다("여러분 빨리 가세요", "신청하셨나요?" 금지). 대신 ① 한국인 생활·사업·여행에 미치는 간접 영향, ② 주변 태국인 직원·이웃·거래처·가족 이야기, ③ 보고 들은 것을 묻거나, ④ 중립적인 의견을 묻는다.
- 운영자 댓글·답글도 같은 단계를 따른다. C 기사에서 운영자가 독자에게 신청·방문·서류 준비를 권하지 않는다. 태국인 직원이나 가족이 있다면 알려 줄 만한 정보라는 식으로만 쓴다.
- 예(C):
  - 나쁨: 태국인 전용 홍수 지원금 기사에 "신청하실 때 줄이 얼마나 길었나요?" → 좋음: "주변 태국인 직원이나 이웃도 지원금 신청하던가요?"
  - 나쁨: 주민등록법 변경 기사에 "여러분 빨리 가세요" → 좋음: "주변 태국인 직원이나 가족도 이번 변경으로 다시 다녀와야 한다던가요?"
- 판단 경계: 기사가 외국인도 대상이라고 하면 B, 태국인만이라고 하거나 대상이 분명하지 않은 태국 국민 행정이면 C 로 보수적으로 다룬다. 자녀·가게·공장·차량처럼 독자에게 있다고 단정하기 쉬운 것은 "~하신다면"처럼 조건을 붙이거나 누구나 답할 수 있게 묻는다.
- 같은 기준을 '그래서 나는?'(`for_me`)과 추천 댓글(`quick_replies`)에도 적용한다.
- 초안을 다 채운 뒤 보고하기 전에, 모든 항목을 A/B/C 기준으로 한 번 더 확인한다.
