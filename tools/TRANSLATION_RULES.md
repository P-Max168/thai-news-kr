# 번역 규칙 (Mingoo 확정, 2026-10-03) — 모든 판에 반드시 적용

[역할] 태국 X(트위터) 실시간 트렌드와 뉴스를 한국어로 번역한다. 독자는 태국 파타야 등에 사는 한국인.

[공통 원칙]
- 직역 금지. 한국 사람이 읽기에 자연스러운 한국어.
- 원문의 사실·숫자·감정 강도 유지. 원문에 없는 정보나 평가 추가 금지.
- 번역문 앞뒤에 "번역했습니다" 같은 군더더기 금지.
- 사건의 핵심과 주요 정보를 먼저 전달.
- 원문의 구어체, 감정, 농담, 비꼼, 의문·감탄을 문맥에 맞게 살린다.

[제목]
- 클릭하고 싶게 임팩트 있게. 의역·어순 변경·강조 허용.
- 핵심 사실·의미에서 벗어나지 않기. 지어내기·과장·왜곡 금지.
- 짧고 강한 뉴스 제목체(명사형 종결 또는 "~다").
- 예외: 사고·사망·성범죄·피해자가 있는 기사는 임팩트는 살리되 선정적으로 쓰지 않는다.

[본문]
- 간결하고 정확한 뉴스체. 의역 최소화.
- X 게시글·사용자 반응은 짧고 자연스러운 SNS 구어체로 현지 분위기를 살린다. 단, X 게시글 원문을 직접 수집하지 않으므로 "현지 반응"은 뉴스 기사에 인용된 반응만 옮긴다.
- 이모지와 해시태그는 그대로 유지.
- 태국어 특유의 완곡 표현·풍자는 의미가 자연스럽게 전달되게.
- 심한 욕설·비하 표현은 감정은 살리되 순화하거나 일부를 가린다(예: "X발"). 공유되는 사이트이므로.

[고유명사·숫자]
- 인명·지명은 한국 통용 표기 우선(Pattaya→파타야, Bangkok→방콕).
- 통용 표기가 없으면 한글 음역 + 첫 등장 시 괄호에 영어(로마자) 표기 병기. 태국 글자는 쓰지 않는다. 예: 아누틴(Anutin).
- 같은 직함·기관명은 항상 같은 번역어.
- 금액은 바트(THB) 유지하고, 모든 금액(작은 금액 포함)에 원화 환산을 괄호로 덧붙인다. 바트와 원화 모두 소수점은 반올림해 정수로만 쓴다(예: 45.50바트 → 46바트(약 1,900원)). 한 판 안에서는 그날 환율 하나로 통일한다(판 데이터/README에 사용 환율 기록).
- 불기(B.E.) 연도는 서기로 변환(2569→2026).

[모호할 때]
- 번역 문장의 의미가 불확실하면 가장 가능성 높은 번역을 쓰고 끝에 "(원문 의미 불확실)" 표시.
- X 트렌드 해시태그 설명을 확인할 수 없으면 기존대로 "확인 안 됨" 표시.

- (2026-10-03 Mingoo 요청) trends24 해시태그 목록을 기사 카드로 만들지 말 것. 트렌드는 트렌드 상자에만 표시하고, SNS 탭에는 실제 화제 기사만 넣는다. 기존 판의 trends24 출처 카드는 개편 시 제거.
- 태국 면적 단위는 괄호로 ㎡와 평을 병기하고 정수로 반올림한다. 1라이(rai)=1,600㎡≈484평, 1응안(ngan)=400㎡≈121평, 1따랑와(tarang wa)=4㎡≈1.21평. 예: 35라이(약 56,000㎡, 약 16,940평).
