## 개발봇 수정 제안(재발 방지) — 앱은 이번에 안 고침

1. **상태 값을 셋으로**: `status ∈ {open_verified, closed_suspected, unknown}`. 근거 없으면 **무조건 unknown**(화면 '영업 여부 확인 안 됨'). '폐업 표시 없음' 문구·`("status", 1)` 삭제.
2. **'확인됨'은 근거와 함께만**: `verify = {url, marker_text, checked_at(방콕 시간), method, by}` 가 있을 때만 ✅. `checked` 는 '받은 날'(`fetched_at`)과 '확인한 날'(`verified_at`)로 나눔. 맨 위 '실제로 확인한 가게 N곳' 은 verify 있는 곳만 셈.
3. **초록불 조건**: `openState()` 는 `status === open_verified` 이고 `verified_at` 이 90일 안일 때만 계산. `closed_suspected` 는 목록에서 숨김(운영자 승인함으로), `unknown`·`old` 는 초록불 없이 회색.
4. **가게 고유번호로 맞추기**: Google 쪽은 이름 검색이 아니라 place_id/cid 로, OSM 쪽은 좌표 거리(예: 150m 안)+이름 비슷함 둘 다 맞을 때만 같은 가게. 검색 결과 목록 화면에서 표시 글 읽기 금지(가게 쪽에서만).
5. **폐업 표시 읽기 규칙**: 'Permanently closed / Temporarily closed / 폐업 / 임시 휴업' 을 **가게 쪽 제목 바로 아래**에서만 찾고, 못 읽으면 unknown(절대 open 아님). OSM 은 `disused:*`·`was:*`·`opening_hours=closed`·`check_date` 를 함께 받아 기록.
6. **다시 확인**: 한식·한인·광고 가게는 30일, 나머지 90일마다(공식 API 를 쓰게 되면 Places API `businessStatus` 를 요청 필드에 명시, 빠지면 unknown). 회귀 검사 31번을 '근거 URL·확인일 없는 ✅ 0곳, 180일 지난 verified 0곳'으로 바꿈.
7. **사람 확인 줄**: 폐업 의심·확인 불가 목록을 승인함에 올려 P_Max·제보(카톡 '정보 틀림')로 닫음. 제보 들어오면 즉시 unknown 으로 내림.
8. **지도 버튼**: OSM 카드는 `query=이름 + Pattaya`(또는 좌표만 `query=위도,경도`)로 바꿔 'can't find' 없애기.
